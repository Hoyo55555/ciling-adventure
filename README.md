# 詞靈冒險．翡翠之卷

以 GBA 像素 RPG 為風格靈感的**國中國文學習遊戲**。玩家選擇世界觀、拿起武器冒險、挑戰關主——而**每一次攻擊都是一道國文題**。

> 純網頁遊戲，免安裝、免網路：直接用瀏覽器開啟 `index.html` 就能玩。電腦、平板、手機都可以。

## 遊戲特色（試玩版：第一章）

| 項目 | 說明 |
|---|---|
| 三種世界觀 | 🏫 國中生涯、🖌️ 文人墨客生涯、⚔️ 俠客生涯，各有不同的人物、關主、武器與介面外框 |
| 角色生成 | 名字、性別、膚色（6）、髮色（14）、表情（9）、服裝款式（褲裝／裙裝／套裝）、上衣／配色／下身顏色；名號可隨機或自訂；名字與名號會過濾不雅與 18 禁字詞（可在 js/config.js 增加禁用字） |
| 武器系統 | 每個世界 30 種武器（三世界名稱不同、可互相轉換），各自擅長不同題型；最多攜帶 3 件，戰鬥中可切換 |
| 武器熟練度 | 用武器答對題目就會累積熟練度，升級後學會新招式（取代寵物養成） |
| 武器妖與碎片 | 野生怪物是武器幻化的Ｑ版「武器妖」，打倒後有機率掉落碎片，集滿 5 片可合成該武器 |
| 高階附加效果 | 良品：熟練度 +1；精品：剋制威力 +15%；珍品：答對回血 3%；絕品：剋制文氣 +1；神品：被剋制不減威力 |
| 稀有度與升階 | 凡品（白）→ 良品（綠）→ 精品（藍）→ 珍品（紫）→ 絕品（金）→ 神品（紅）；同名同階武器可合成升階（3／3／4／4／5 件），守護神器（彩）只能由劇情取得 |
| 城鎮 | 城鎮內沒有草叢、怪物與對戰；家、保健室（醫館／藥鋪）、商店可以走進室內，隔著櫃檯對話；關主在關卡建築中 |
| 五行相剋 | 金剋木、木剋土、土剋水、水剋火、火剋金；字音字形＝金、詞義成語＝木、修辭閱讀＝水、詩詞＝火、文言常識＝土；剋制 ×1.5、被剋 ×0.7 |
| 答題戰鬥 | 橫向對峙畫面；每招對應一種題型，**答對才命中**；敵人出招時也可能出題，答對就閃避 |
| 文氣必殺 | 每答對一題累積 1 格文氣，集滿 5 格可施展必殺技 |
| 看得見的敵人 | 武器妖在道路草叢中巡邏，靠近會追過來，碰到才開戰 |
| 章節結構 | 城鎮 → 道路（寶箱、支線任務、勁敵）→ 關主 → 章節結算 |
| 存檔 | 3 個欄位、自動存檔；可設定雲端存檔（班級＋座號＋密碼登入，存進老師的 Google 試算表，見〈雲端存檔設定說明.md〉） |
| 劇情分支 | 劇情中有回答選項，選擇不同會走向兩條路線，影響 NPC、對話與守護神器 |
| 守護神器 | 每個世界兩件（依路線不同），各有特殊能力：護心、文思泉湧、慧眼、破妄、回春、再思 |
| 錯題強化 | 戰鬥中有 35% 機率重出錯題本裡的同類題目，答對即從錯題本移除 |
| 通關 | 冒險成績單（可下載圖片）→ 轉生到其他世界（保留等級、武器、學習紀錄）或重新開始 |
| 學習功能 | 錯題本（可複習）、各題型答對率、建議加強項目 |
| 教師設定 | 用教師帳號登入後才會出現（預設：班級 T、座號 0、密碼 1234）；匯入 CSV／JSON 題庫、依課次篩選出題、匯出題庫 |
| 任務提示 | 該對話的對象頭上會閃爍提示：黃色「!」主線、藍色「!」支線、黃色「?」可回報 |

題型分類：字音、字形、詞義、成語、修辭、文言、詩詞、常識、閱讀
題目形式：選擇題、是非題、填空題、排序題

## 操作方式

| 按鍵 | 功能 |
|---|---|
| 方向鍵／WASD | 移動、選擇 |
| Z／空白鍵 | 確認、對話、調查 |
| X／Esc | 取消；在地圖上按住可奔跑 |
| Enter／M | 開啟書冊選單 |
| H／⌂ 主畫面鍵 | 回到主畫面（自動存檔） |
| T（標題畫面，教師登入後） | 開啟教師設定 |

手機可使用畫面下方的虛擬按鍵，選單與題目也能直接點選。

## 如何加入國文題目

### 方法一：在遊戲內匯入（老師最方便）
1. 開啟遊戲 → 標題畫面選「教師設定」
2. 點「下載 CSV 範本」，用 Excel 或 Google 試算表編輯
3. 另存為 CSV（UTF-8）後，點「匯入（取代）」或「匯入（附加）」

> 匯入的題庫存在**該台電腦的瀏覽器**中。要讓所有學生都用到新題目，請用方法二。

### 方法二：寫進遊戲檔案（所有人都會用到）
編輯 `js/data_questions.js` 中的 `QUESTIONS_SAMPLE` 陣列，格式說明寫在檔案開頭。

### CSV 欄位

| 欄位 | 說明 |
|---|---|
| 題型 | 選擇／是非／填空／排序 |
| 分類 | 字音、字形、詞義、成語、修辭、文言、詩詞、常識、閱讀（也接受「文言文」「國學常識」「閱讀測驗」等常見說法） |
| 難度 | 1～3 |
| 課次 | 例如「第三課 陋室銘」，可在教師設定中依課次開關 |
| 題目 | 題幹 |
| 選項1～4 | 選擇題選項；排序題依**正確順序**填入片段 |
| 答案 | 選擇題填 A／B／C／D（或 1～4）；是非題填 O／X；填空題可填多個可接受答案，用 `/` 分隔 |
| 解析 | 答題後顯示，是學習重點 |

範例見 [`題庫範本.csv`](題庫範本.csv)。

## 檔案結構

```
index.html              遊戲入口
css/style.css           像素風介面（依世界觀換外框）
js/engine.js            輸入、動畫、音效與 8-bit 音樂
js/gfx.js               程式生成的像素圖（敵人、人物、武器、地圖圖塊）
js/config.js            遊戲設定（雲端存檔網址）
js/cloud.js             雲端存檔與登入
js/data_questions.js    題庫與 CSV 匯入匯出  ← 國文內容放這裡
js/data_game.js         題型、武器、敵人、道具、地圖版型
js/data_worlds.js       三種世界觀的劇情、人物、關主
js/ui.js                對話框、選單、答題面板
js/overworld.js         大地圖移動、NPC、遇敵
js/battle.js            答題戰鬥（橫向對峙、文氣必殺）
js/menus.js             書冊選單、存檔、成績單、教師設定、角色生成
js/main.js              主程式
國文資料/               放國文科原始資料（課文、講義、考卷）
gas/Code.gs             雲端存檔用的 Google Apps Script
```

## 發布成網站（GitHub Pages）

推送到 GitHub 後：Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
約一分鐘後會得到網址，學生用手機或電腦打開就能玩。
