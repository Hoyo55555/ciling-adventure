# 詞靈冒險．翡翠之卷

以《寶可夢 綠寶石》為風格靈感的**國中國文學習 RPG**。玩家在像素地圖上冒險、在草叢遇見「詞靈」、挑戰關主收集徽章——而**每一次攻擊都是一道國文題**。

> 純網頁遊戲，免安裝、免網路：直接用瀏覽器開啟 `index.html` 就能玩。電腦、平板、手機都可以。

## 遊戲特色

| 項目 | 說明 |
|---|---|
| 三種世界觀 | 🏫 國中生涯、🖌️ 文人墨客生涯、⚔️ 俠客生涯，各有不同的劇情、人物、關主與用語 |
| 角色生成 | 名字、性別、髮色、服裝、名號（班級社團／字號／江湖名號）可自選或一鍵隨機生成 |
| 答題戰鬥 | 每招對應一種題型，**答對才命中**；對手出招時也可能出題，答對就能閃避 |
| 弱點系統 | 每種詞靈都有弱點題型（例：錯字蟲怕「字形」），打中弱點傷害兩倍 |
| 收服與養成 | 丟「墨球」收服野生詞靈，升級學新招 |
| 學習功能 | 答錯自動收進**錯題本**可複習；**學習紀錄**顯示各題型答對率並建議加強項目 |
| 教師設定 | 匯入 CSV／JSON 題庫、依課次篩選出題、匯出題庫 |

題型分類（招式屬性）：字音、字形、詞義、成語、修辭、文言、詩詞、常識、閱讀
題目形式：選擇題、是非題、填空題、排序題

## 操作方式

| 按鍵 | 功能 |
|---|---|
| 方向鍵／WASD | 移動、選擇 |
| Z／空白鍵 | A：確認、對話、調查 |
| X／Esc | B：取消；在地圖上按住可奔跑 |
| Enter／M | START：開啟選單 |

手機可使用畫面下方的虛擬按鍵，選單與題目也能直接點選。

## 如何加入國文題目

### 方法一：在遊戲內匯入（老師最方便）
1. 開啟遊戲 → 標題畫面選「教師設定」
2. 點「下載 CSV 範本」，用 Excel 或 Google 試算表編輯
3. 另存為 CSV（UTF-8）後，點「匯入（取代）」或「匯入（附加）」

> 匯入的題庫存在**該台電腦的瀏覽器**中。要讓所有學生都用到新題目，請用方法二。

### 方法二：寫進遊戲檔案（所有人都會用到）
編輯 `js/data_questions.js` 中的 `QUESTIONS_SAMPLE` 陣列，格式說明寫在檔案開頭。

### CSV 欄位

| 欄位 | 說明 |
|---|---|
| 題型 | 選擇／是非／填空／排序 |
| 分類 | 字音、字形、詞義、成語、修辭、文言、詩詞、常識、閱讀（也接受「文言文」「國學常識」「閱讀測驗」等常見說法） |
| 難度 | 1～3 |
| 課次 | 例如「第三課 陋室銘」，可在教師設定中依課次開關 |
| 題目 | 題幹 |
| 選項1～4 | 選擇題選項；排序題依**正確順序**填入片段 |
| 答案 | 選擇題填 A／B／C／D（或 1～4）；是非題填 O／X；填空題可填多個可接受答案，用 `/` 分隔 |
| 解析 | 答題後顯示，是學習重點 |

範例見 [`題庫範本.csv`](題庫範本.csv)。

## 檔案結構

```
index.html              遊戲入口
css/style.css           GBA 綠寶石風格介面
js/engine.js            輸入、動畫、音效與 8-bit 音樂
js/gfx.js               程式生成的像素圖（詞靈、人物、地圖圖塊）
js/data_questions.js    題庫與 CSV 匯入匯出  ← 國文內容放這裡
js/data_game.js         題型、招式、詞靈、道具、地圖版型
js/data_worlds.js       三種世界觀的劇情、人物、關主
js/ui.js                對話框、選單、答題面板
js/overworld.js         大地圖移動、NPC、遇敵
js/battle.js            答題戰鬥
js/menus.js             各種選單、教師設定、角色生成
js/main.js              主程式
國文資料/               放國文科原始資料（課文、講義、考卷）
```

## 發布成網站（GitHub Pages）

推送到 GitHub 後：Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
約一分鐘後會得到網址，學生用手機或電腦打開就能玩。
